01About me

I build the parts of an application nobody ever sees, and make sure they keep working.

Most of my projects start from a small annoyance: a report that takes too long to generate, data that never quite matches between two systems, a process still done by hand every Monday morning. I like breaking those problems down into APIs, schemas, and background jobs that the next person can actually read. Outside of class I write about backend engineering on Medium, and I have a habit of rebuilding things I have already built, only cleaner the second time.

03Portfolio

CDC Postgres to ClickHouse

Streams row-level changes out of Postgres and into ClickHouse in near real time, so heavy analytics queries never touch the production database.

Postgres, Kafka, ClickHouse, Debezium

Campus Library API

REST API for book loans and returns with JWT auth, role-based access for students and staff, and an overdue-fine calculator that runs nightly.

Rust, Actix Web, PostgreSQL, JWT

Event Ticketing Service

Handles seat reservations for campus events. A hold timer in Redis locks a seat during checkout, so two people can never pay for the same chair.

Go, Fiber, Redis, Docker

Notification Dispatch Service

Queues outgoing email and push notifications, retries failures with exponential backoff, and parks anything still broken in a dead-letter queue instead of losing it silently.

Python, FastAPI, Celery, RabbitMQ

Weather Dashboard

Single-page dashboard with a seven-day forecast chart. API responses are cached in local storage, so a repeat visit renders before the network answers.

JavaScript, Fetch API, Chart.js, OpenWeather

Log Search CLI

Command-line tool that tails JSON logs from several services at once and filters them with a small query grammar. The last hour stays in memory, so re-running a search is instant.

Rust, Tokio, Clap, SQLite
